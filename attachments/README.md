# Attachments

Add downloadable files here (PDF, images, writing). Then add a row to `manifest.json`:

```json
{
  "items": [
    {
      "title": "Talk one-pager",
      "file": "talk-onepager.pdf",
      "kind": "PDF"
    }
  ]
}
```

`file` is the filename in this folder. The site lists whatever is in `items`.
